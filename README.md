### Документация для программы преобразования текстового представления числа в числовое с форматированием

#### Общее описание
Программа предназначена для преобразования текстового представления числа (например, "Five hundred million") в числовое значение с возможностью форматирования результата (например, "500,000,000"). Программа поддерживает базовые числительные (от "one" до "ten") и множители ("hundred", "thousand", "million").

#### Основные функции

1. **getNumber(word string) int**
   - **Описание:** Возвращает числовое значение, соответствующее переданному слову. Если слово не является числительным, возвращает 0.
   - **Параметры:**
     - `word` (string): Слово, представляющее числительное (например, "five").
   - **Возвращаемое значение:** Числовое значение (например, 5 для "five").

2. **getHundredAmount(word string) int**
   - **Описание:** Возвращает множитель, соответствующий переданному слову. Если слово не является множителем, возвращает 0.
   - **Параметры:**
     - `word` (string): Слово, представляющее множитель (например, "hundred").
   - **Возвращаемое значение:** Множитель (например, 100 для "hundred").

3. **setPointsToNumber(num int) string**
   - **Описание:** Форматирует число, добавляя запятые для разделения тысяч.
   - **Параметры:**
     - `num` (int): Число, которое нужно отформатировать.
   - **Возвращаемое значение:** Отформатированная строка (например, "500,000,000" для 500000000).

4. **getNumberFromString(text string, usePoint bool) string**
   - **Описание:** Преобразует текстовое представление числа в числовое значение с возможностью форматирования.
   - **Параметры:**
     - `text` (string): Текст, содержащий числительные и множители (например, "Five hundred million").
     - `usePoint` (bool): Флаг, указывающий, нужно ли форматировать результат с запятыми.
   - **Возвращаемое значение:** Строка, представляющая числовое значение (например, "500,000,000" для "Five hundred million" с `usePoint=true`).

#### Пример использования

```go
func main() {
    NEEDED_STRING := "Five hundred million"
    result := getNumberFromString(NEEDED_STRING, true)
    fmt.Println(result) // 500,000,000
}
```

#### Логика работы
1. Программа разбивает входной текст на отдельные слова.
2. Для каждого слова проверяется, является ли оно числительным или множителем.
3. Числительные суммируются, а множители умножают текущую сумму.
4. Если флаг `usePoint` установлен в `true`, результат форматируется с добавлением запятых для разделения тысяч.

#### Поддерживаемые числительные и множители
- **Числительные:** "one", "two", "three", "four", "five", "six", "seven", "eight", "nine", "ten".
- **Множители:** "hundred", "thousand", "million".

#### Ограничения
- Программа не поддерживает отрицательные числа.
- Программа не поддерживает дробные числа.
- Программа не поддерживает числительные больше "ten" и множители больше "million".

#### Заключение
Программа предоставляет простой способ преобразования текстового представления числа в числовое значение с возможностью форматирования результата. Она может быть полезна в задачах, где требуется обработка текстовых данных, содержащих числительные.
